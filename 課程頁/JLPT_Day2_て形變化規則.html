JLPT N5–N3 每日自學課程｜Day 2（N5）：て形變化規則

上一課我哋學咗動詞點樣分做五段、一段同不規則三大類。今日就係用返呢個分類，學日文最重要、用得最密嘅一個變化——て形。學識咗て形，你先至講到「請你……」「我而家……緊」「食完飯之後去……」呢啲日常句式，可以話係由「識單字」升級到「識講嘢」嘅關鍵一步。

一、て形係咩嚟？點解咁重要？

「て形」係動詞嘅一種活用形，本身唔表示時態，佢嘅作用係「接口」——用嚟接住後面嘅句型，例如：

  • 食べてください。（請食。）
  • 今、勉強しています。（而家讀緊書。）
  • ここで写真を撮ってもいいですか？（可唔可以喺度影相？）

換句話講，て形就好似樂高積木嘅「凸粒」，冇咗佢，後面嘅句型全部接唔埋。JLPT N5 嘅文法題，有接近三成直接或間接考て形，所以今日一定要練到熟。

二、五段動詞（う動詞）嘅て形——音便規則

五段動詞嘅て形變化係成個 N5 最考起人嘅位，因為佢唔係齋加「て」，而係詞尾會變音（日文叫「音便」）。記住以下呢個表，係今日嘅重中之重：

詞尾 て形變化 例
く → いて 書く → 書いて（かいて）
ぐ → いで 泳ぐ → 泳いで（およいで）
す → して 話す → 話して（はなして）
む・ぶ・ぬ → んで 飲む → 飲んで（のんで）／遊ぶ → 遊んで（あそんで）／死ぬ → 死んで（しんで）
う・つ・る → って（促音） 買う → 買って（かって）／待つ → 待って（まって）／帰る → 帰って（かえって）

逐個規則詳細拆解

1. 「く」尾 → いて 書（か）く → 書（か）いて／聞（き）く → 聞（き）いて／歩（ある）く → 歩（ある）いて

  • 例句：手紙（てがみ）を書（か）いて、ポストに入（い）れました。（寫完信之後，放入咗郵筒。）

2. 「ぐ」尾 → いで（注意係「で」唔係「て」！） 泳（およ）ぐ → 泳（およ）いで／急（いそ）ぐ → 急（いそ）いで

  • 例句：夏（なつ）に海（うみ）で泳（およ）いで、とても楽（たの）しかったです。（夏天喺海度游水，好開心。）

3. 「す」尾 → して 話（はな）す → 話（はな）して／出（だ）す → 出（だ）して／貸（か）す → 貸（か）して

  • 例句：もう一度（いちど）話（はな）してください。（唔該再講一次。）

4. 「む・ぶ・ぬ」尾 → んで（撥音便） 飲（の）む → 飲（の）んで／読（よ）む → 読（よ）んで／遊（あそ）ぶ → 遊（あそ）んで／呼（よ）ぶ → 呼（よ）んで

  • 例句：毎晩（まいばん）、本（ほん）を読（よ）んでから寝（ね）ます。（每晚睇完書先瞓覺。）
  • 例句：友達（ともだち）と公園（こうえん）で遊（あそ）んでいます。（同朋友喺公園玩緊。）

5. 「う・つ・る」尾 → って（促音便） 買（か）う → 買（か）って／会（あ）う → 会（あ）って／待（ま）つ → 待（ま）って／立（た）つ → 立（た）って／帰（かえ）る → 帰（かえ）って／作（つく）る → 作（つく）って／分（わ）かる → 分（わ）かって

  • 例句：駅（えき）の前（まえ）で友達（ともだち）を待（ま）っています。（喺站前面等緊朋友。）
  • 例句：昨日（きのう）、パンを作（つく）って、家族（かぞく）と食（た）べました。（尋日整咗麵包，同屋企人一齊食。）

⚠️ 超級例外：行く

行（い）く → 行（い）って（唔係「行いて」！）

呢個係五段動詞て形唯一嘅特例，「く」尾但係變促音。JLPT 好鍾意考呢個位，一定要死記。

  • 例句：来週（らいしゅう）、京都（きょうと）へ行（い）って、お寺（てら）を見（み）ます。（下星期去京都，睇寺院。）

三、一段動詞（る動詞）——最簡單，去る加て

一段動詞完全冇音便，將詞尾「る」換成「て」就搞掂：

  • 食（た）べる → 食（た）べて
  • 見（み）る → 見（み）て
  • 起（お）きる → 起（お）きて
  • 教（おし）える → 教（おし）えて
  • 忘（わす）れる → 忘（わす）れて

例句：毎朝（まいあさ）六時（ろくじ）に起（お）きて、ジョギングをします。（每日朝早六點起身，去慢跑。）

四、不規則動詞——淨係得兩個，直接背

  • する → して
  • 来（く）る → 来（き）て

連埋佢哋嘅複合動詞都一樣：勉強（べんきょう）する → 勉強して／持（も）って来（く）る → 持（も）って来（き）て。

  • 例句：毎日（まいにち）、日本語（にほんご）を勉強（べんきょう）しています。（每日都讀緊日文。）

五、て形嘅基本用法（今日先認識，聽日深講）

  1. 連接動作：朝（あさ）ご飯（はん）を食（た）べて、学校（がっこう）へ行（い）きます。（食完早餐去學校。）
  2. 請求：ちょっと待（ま）ってください。（唔該等一等。）
  3. 進行／狀態：今（いま）、雨（あめ）が降（ふ）っています。（而家落緊雨。）
  4. 並列原因：頭（あたま）が痛（いた）くて、会社（かいしゃ）を休（やす）みました。（頭痛，所以請咗假。）

【常見錯誤／伏位】

  • ❌ 行（い）いて → ✅ 行（い）って（唯一特例，考試必出！）
  • ❌ 泳（およ）いて → ✅ 泳（およ）いで（「ぐ」尾要變濁音「で」）
  • ❌ 飲（の）む → 飲（の）いて → ✅ 飲（の）んで（「む」尾係撥音便）
  • ❌ 將「帰（かえ）る」「分（わ）かる」當一段動詞，寫成「帰て」「分かて」——記住上一課教過：見（み）る、起（お）きる 呢類先係一段；帰る、分かる、作（つく）る 係五段，要變「って」！
  • ❌ 忘記「ぬ」尾動詞：現代日文「ぬ」尾淨係得 死（し）ぬ 一個，變「死（し）んで」。

【記憶技巧】

  • 口訣法：「き・ぎ・し→いて・いで・して；み・び・に→んで；い・ち・り→って」。背熟「きぎし／みびに／いちり」三組假名，對應三種音便。
  • 諗「音樂感」：「んで」「って」都係為咗讀起身順口。試吓讀「のむて」同「のんで」，邊個順？日文本來就係點順口點變。
  • 卡片法：將 15 個常用五段動詞寫喺卡片正面，て形寫背面，每日沖涼前抽 5 張自測，一星期就慣晒。

六、閱讀短文（運用今日嘅て形）

わたしの一日（いちにち）

毎朝（まいあさ）、七時（しちじ）に起（お）きて、顔（かお）を洗（あら）って、朝（あさ）ご飯（はん）を食（た）べます。それから、家（いえ）を出（で）て、駅（えき）まで歩（ある）いて、電車（でんしゃ）に乗（の）って会社（かいしゃ）へ行（い）きます。

昼（ひる）は、同僚（どうりょう）と一緒（いっしょ）に食堂（しょくどう）へ行（い）って、昼（ひる）ご飯（はん）を食（た）べて、お茶（ちゃ）を飲（の）んで、少（すこ）し休（やす）みます。

夜（よる）、家（いえ）に帰（かえ）って、シャワーを浴（あ）びて、晩（ばん）ご飯（はん）を作（つく）って食（た）べます。それから、本（ほん）を読（よ）んだり、日本語（にほんご）を勉強（べんきょう）したりして、十一時（じゅういちじ）ごろ寝（ね）ます。

中譯：我嘅一日——每日朝早七點起身，洗完面，食早餐。之後出門口，行去車站，搭電車去公司。中午同同事一齊去飯堂，食完午餐、飲完茶，休息一陣。夜晚返到屋企，沖完涼，整晚餐嚟食。之後讀吓書、學吓日文，十一點左右就瞓覺。

七、核心文法表

句型／規則 接續 意思 例句
く→いて 五段「く」尾 音便（清音） 書（か）いてください。（請寫。）
ぐ→いで 五段「ぐ」尾 音便（濁音） 泳（およ）いでいます。（游緊水。）
す→して 五段「す」尾 音便 話（はな）してもいいです。（可以講。）
む・ぶ・ぬ→んで 五段「む・ぶ・ぬ」尾 撥音便 飲（の）んでください。（請飲。）
う・つ・る→って 五段「う・つ・る」尾 促音便 待（ま）っています。（等緊。）
行く→行って 特例 唯一例外 行（い）ってきます。（我去去就返。）
一段動詞：る→て 去る加て 無音便 食（た）べてから寝（ね）ます。（食完先瞓。）
する→して 不規則 — 勉強（べんきょう）しています。（讀緊書。）
来る→来（き）て 不規則 — ここへ来（き）てください。（請過嚟。）
て形＋て形 動作連接 做完 A 再做 B 起（お）きて、顔（かお）を洗（あら）います。（起咗身洗面。）

九、小測驗（5 題）

第 1 題（選擇題）「泳（およ）ぐ」嘅て形係邊個？ A. およいで　　B. およいて　　C. およんで　　D. およって

第 2 題（選擇題）「行（い）く」嘅て形係邊個？ A. いいて　　B. いって　　C. いきて　　D. いんで

第 3 題（填充題）請寫出「読（よ）む」嘅て形：＿＿＿＿

第 4 題（填充題）請寫出「待（ま）つ」嘅て形：＿＿＿＿

第 5 題（選擇題）「食（た）べる・見（み）る・起（お）きる」呢類一段動詞嘅て形規則係： A. 詞尾變促音「って」　　B. 詞尾變撥音「んで」　　C. 去「る」加「て」　　D. 去「る」加「って」

答案及詳細解釋

  1. A（およいで）——「ぐ」尾要變濁音「いで」，唔係清音「いて」。記住：く→いて（清）、ぐ→いで（濁）。
  2. B（いって）——行く係唯一特例，「く」尾但變促音「って」，考試必考！
  3. 読（よ）んで——「む」尾屬撥音便，變「んで」。
  4. 待（ま）って——「つ」尾屬促音便，變「って」。
  5. C（去「る」加「て」）——一段動詞冇音便，最簡單：食べる→食べて、見る→見て、起きる→起きて。
