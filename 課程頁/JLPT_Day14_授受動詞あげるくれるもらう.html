Day 14（N4）：授受動詞（あげる・くれる・もらう）

📅 課程日期：2026-11-10 ｜ 📊 級別：N4 ｜ ⏱️ 預計閱讀時間：20–30 分鐘

上一課（Day 13）學咗使役形「我叫人做嘢」，今日嚟到 N4 另一個必考重頭戲——授受動詞！咩係「授受」？即係俾嘢同人（授）同埋收嘢（受）。日文入面「俾」同「收」唔係一個動詞搞掂，而係要睇邊個俾邊個、視點企喺邊，分咗三個動詞：あげる・くれる・もらう。呢個係香港人學日文最容易撞牆嘅位之一，因為廣東話一句「佢俾咗我」就講完，日文就要揀詞。不過唔使驚，今日我會用最貼地嘅方式幫你拆開佢，睇完你就會明白點解日劇入面啲人講「くれた」嗰陣會笑得咁開心！

一、咩係授受動詞？視點係靈魂！

廣東話講「俾」同「收」好簡單：

  • 我俾咗本書佢。（我 → 佢）
  • 佢俾咗本書我。（佢 → 我）
  • 我收咗佢本書。（佢 → 我）

頭兩句廣東話都係用「俾」一字，但日文唔同方向要用唔同動詞：

日文 方向 廣東話意思
あげる 我／我這邊 → 別人 我俾人
くれる 別人 → 我／我這邊 人俾我
もらう 我／我這邊 ← 別人 我收人哋

重點嚟喇：日文授受動詞最緊要嘅係視點（視点・してん）——句子的「攝影機」一定企喺自己（或者自己人呢一組，例如屋企人、公司同事）嗰邊，向外望。所有「流入嚟我度」嘅嘢用 くれる／もらう，「由我流出去」嘅嘢用 あげる。

💡 記憶技巧：諗住自己間屋。「有人入嚟我屋企送嘢畀我」→ くれる（入嚟嗰個動作）；「我出門送嘢畀人」→ あげる（出去嗰個動作）；「我喺屋企收嘢」→ もらう（我係接收方）。くれる 永遠指住自己，あげる 永遠離開自己。

二、あげる：由我這邊俾出去

1. 基本句型

名詞１（俾的人）は 名詞２（收的人）に 物を あげる

  • 私は友達に本をあげました（わたし は ともだち に ほん を あげました） → 我俾咗本書個朋友。
  • 私は母に花をあげる（わたし は はは に はな を あげる） → 我會送花俾阿媽。（母親節諗住咁做啦！）

留意粒助詞：收嘅人用「に」，俾嘅嘢用「を」。呢個配搭同動作對象（～に）＋目的物（～を）一樣，例如「本を友達に読んであげる」。

2. 兄弟詞：やる 同 差し上げる

あげる 仲有兩個「親戚」，按對方身份揀：

詞 對象 例子
やる 平輩以下、細路、動物、植物 犬に餌をやる（餵狗食嘢）／弟にお金をやった（俾咗錢個細佬）
あげる 平輩、朋友 友達にプレゼントをあげた
差し上げる（さしあげる） 長輩、上司、客戶（尊敬） 先生にお土産を差し上げた（送咗手信俾老師）
  • 例句：私は毎朝、庭の花に水をやります（わたし は まいあさ、にわ の はな に みず を やります）→ 我每日朝早淋花。
  • 例句：社長に資料を差し上げました（しゃちょう に しりょう を さしあげました）→ 我哋（俾）社長遞咗資料。（對上司用敬語版！）

⚠️ 常見錯誤／伏位：唔好對長輩直接講「社長にあげました」——聽落好冇禮貌，好似話社長係你下屬咁。對上級一定用 差し上げる。呢個已經係敬語嘅雛形，Day 15 敬語課會再深入。

三、くれる：由外面流入嚟我度

1. 基本句型

名詞１（俾的人）が 名詞２（收的人＝我這邊）に 物を くれる

  • 友達が私に本をくれました（ともだち が わたし に ほん を くれました） → 朋友俾咗本書我。
  • 母が（私に）ケーキを作ってくれた（はは が わたし に ケーキ を つくってくれた） → 阿媽整咗個蛋糕俾我。（有冇 feel 到嗰種開心同感恩？）

留意兩個位：

  1. 俾嘅人係主語，用「が」（唔係「は」，因為重點係「佢俾嘢我」呢個動作本身）。
  2. 「私に」成日省略，因為 くれる 本身就已經暗示咗收嘢嘅係「我／我這邊」：
    • 彼が本をくれた（かれ が ほん を くれた）→ 佢俾咗本書我。（唔使講「私に」都明）

2. 兄弟詞：くださる（尊敬語）

對方係長輩、上司，要用 くださる：

  • 先生が私に辞書をくださいました（せんせい が わたし に じしょ を くださいました） → 老師俾咗本字典我。（有冇留意 くださる 嘅過去式係「くださいました」，而唔係「くださった」？口語會講 くれた，但書面／正式場合用 くださいました。）
  • 部長がお土産をくださいました（ぶちょう が おみやげ を くださいました）→ 部長送咗手信畀我哋。

💡 記憶技巧：「くれる 一字入屋」——呢個字永遠係別人送嘢入嚟我屋企。所以當你聽到日本人講「〜てくれた」「〜をくれた」，個視點一定係企喺講嘢嗰個人度。有冇人用 くれる 形容自己俾嘢人？冇！ 一用就穿崩。

四、もらう：我這邊接收

1. 基本句型

名詞２（收的人＝我這邊）は 名詞１（俾的人）に／から 物を もらう

  • 私は友達に本をもらいました（わたし は ともだち に ほん を もらいました） → 我收咗朋友本書。（＝朋友俾咗本書我，視點轉咗去「我」度睇）
  • 私は兄から古い自転車をもらった（わたし は あに から ふるい じてんしゃ を もらった） → 我問阿哥攞咗部舊單車。

兩個位要留意：

  1. 俾嘅人用「に」或者「から」都得。「に」最常用；「から」喺想強調「由佢度」、或者對方係團體／公司時更自然（例：会社からボーナスをもらった＝收咗公司花紅）。
  2. 主語（收嘅人）用「は」。

2. 兄弟詞：いただく（謙讓語）

收長輩嘅嘢，要用 いただく：

  • 私は先生に本をいただきました（わたし は せんせい に ほん を いただきました） → 我收咗老師本書。（謙虛咁講「我收咗」）
  • 口頭禪：いただきます（我開動喇！）都係同一個字根——食人哋整嘅飯＝「收」人哋嘅嘢，所以食飯前講呢句都係授受動詞嘅禮儀延伸！

💡 記憶技巧：三個詞諗成一個循環——あげる（出去）→ くれる（入嚟）→ もらう（接住）。日本人送禮嗰陣成日一個推一個：「どうぞ、どうぞ」「いやいや、すみません」，最終有人「もらう」收貨，成個循環先完。

五、大絕招：〜てあげる／〜てくれる／〜てもらう（幫手做嘢）

學咗「俾嘢」，升級做「幫人做嘢／人幫我做嘢」——動詞轉て形，再加授受動詞：

句型 意思 視點
〜てあげる 我幫（佢）做 我做主動幫人
〜てくれる （佢）幫我做 人主動幫我，我好感動
〜てもらう （我）請／承蒙（佢）做 我係受益方

1. 〜てあげる：我幫你做

  • 私は友達に荷物を持ってあげた（わたし は ともだち に にもつ を もってあげた） → 我幫個朋友拎行李。
  • 犬にえさをやってあげる？NO！ 對動物直接用「やる」或者「〜てやる」：犬にえさをやった（餵咗狗）。對寵物其實而家好多人都講「〜てあげる」，因為當寵物係家人，但考試記住正式寫法係 やる。

2. 〜てくれる：人幫我做（充滿感恩）

  • 友達が私の荷物を持ってくれた（ともだち が わたし の にもつ を もってくれた） → 朋友幫我拎咗行李。（超級好人！）
  • 雨の日に、店の人が傘を貸してくれた（あめ の ひ に、みせ の ひと が かさ を かしてくれた） → 落雨嗰日，店員借咗遮俾我。

3. 〜てもらう：請人幫手／承蒙幫忙

  • 私は友達に荷物を持ってもらった（わたし は ともだち に にもつ を もってもらった） → 我請個朋友幫我拎行李。
  • 先生に日本語を教えてもらっています（せんせい に にほんご を おしえてもらっています） → 我請緊老師教我日文。（仲學緊＝〜ています）

4. 同一情景，三個講法！

「阿美幫我執咗間房」可以咁講（視點唔同，味道唔同）：

  1. 私は阿美に部屋を片付けてもらった。（我請佢——感激／麻煩咗人）
  2. 阿美が部屋を片付けてくれた。（佢主動——開心、感動）
  3. 阿美は私の部屋を片付けてあげた。（阿美角度——佢幫咗我，視點企喺阿美度，比如阿美同人講）

⚠️ 常見錯誤／伏位：〜てあげる 唔好用嚟講自己幫長輩做嘢（會有施恩咁嘅傲慢感），對上級用 〜て差し上げる。另外 〜てもらう 前面嘅助詞：幫手嘅人用「に」，千祈唔好寫「〜をもらう」！

六、常見錯誤總整理（考試伏位）

  1. 用錯方向：✕「友達が本をもらった（我俾書朋友）」→ 要用 あげる：友達に本をあげた。もらう 嘅主語一定係收嘢嗰方。
  2. 助詞錯配：✕「友達を本をくれた」→ 收嘅人用「に」：友達に本をくれる（俾人）／友達に／から本をもらう（收人）。
  3. くれる 主語用は：✕「友達は本をくれた」其實口語聽到，但文法測驗正解係「友達が本をくれた」。
  4. 對長輩用原級：✕「先生に本をあげた」→ 要謙敬：先生に本を差し上げた；✕「先生が本をくれた」→ 先生が本をくださった。
  5. 「私に」亂加：くれる 句入面「私に」可以省略；✕「私が私に…」好怪。

💡 記憶技巧：考試見到授受動詞，先問自己三條問題：①嘢流邊個方向？②我企邊度睇？③對方係咪長輩？ 答咗呢三條，答案自動出嚟。

七、今日閱讀短文：誕生日のプレゼント

先唔好睇中譯，自己試吓讀！

昨日は私の誕生日でした。朝起きると、母が（私に）朝ご飯を作ってくれて、その上、好きなケーキも買ってくれました。父は私に新しい自転車をくれました。「大学まで自転車で行きなさい」と言いました。午後、友達が家に来て、みんなでパーティーをしました。友達は私に素敵なマフラーをくれました。私も友達に、前から約束していた本をあげました。とても楽しい一日でした。

中譯：

琴日係我生日。朝早一起身，阿媽整咗早餐俾我，仲買咗我最鍾意嘅蛋糕。老豆俾咗部新單車我，話「踩單車去大學啦」。下晝朋友嚟咗屋企，一齊開派對。朋友送咗條靚頸巾俾我，我又俾咗本應承咗好耐嘅書朋友。真係好開心嘅一日！

短文入面嘅授受動詞逐個捉： - 作ってくれて＋買ってくれました → 阿媽主動幫我（感恩語氣） - くれました（父は） → 人俾我嘢（物品） - くれました（友達は） → 人俾我嘢 - あげました（私は） → 我俾人嘢

十、小測驗（5 題）

Q1（選擇題） 「弟弟俾咗我佢支筆」點講？ - ア．弟は私にペンをもらいました - イ．弟が私にペンをくれました - ウ．弟に私がペンをあげました

Q2（選擇題） 「我送咗手信俾部長」最啱嘅講法係？ - ア．社長に土産をあげました - イ．社長に土産を差し上げました - ウ．社長に土産をくれました

Q3（填充題） 請填助詞：私は友達＿＿本をもらいました。（我收咗朋友本書）

Q4（填充題） 請用 〜てくれる 句式改寫：友達が私の部屋を掃除した。（朋友幫我打扫咗间房）

Q5（選擇題） 「母が（私に）ケーキを作＿＿＿＿＿＿＿、うれしかった」空格最啱填？ - ア．ってもらって - イ．ってあげて - ウ．ってくれて

十一、答案及詳細解釋

Q1：イ（弟が私にペンをくれました） 「弟弟俾嘢我」＝嘢由佢流入嚟我度，視點企喺我度，用 くれる，主語「弟」用 が。ア 錯在もらう 主語係收嘢嗰方（我），唔可以係弟弟；ウ 方向反咗，變咗「我俾筆弟弟」。

Q2：イ（社長に土産を差し上げました） 對象係長輩（社長），「俾」要用謙讓版 差し上げる。ア 用普通 あげる 對上級好冇禮貌；ウ くれる 方向錯（社長俾我先至用くれる）。

Q3：に（或者「から」都得，考試正解通常係 に） もらう 句型：收嘅人（私）は＋俾嘅人＋に＋物をもらう。「から」都可以，但基礎題答 に 最穩陣。

Q4：友達が私の部屋を掃除してくれた。 原句「朋友打扫咗我间房」冇講明係幫我，但題目要求用 〜てくれる 句式，即係強調「佢幫我做，我受益」：動詞 掃除する → 掃除して＋くれた。留意主語用 が：友達が。

Q5：ウ（作ってくれて） 「阿媽整咗蛋糕（俾我），我好開心」——嘢由阿媽流入嚟我度，用 〜てくれる。ア 「作ってもらって」語法上通（我請阿媽整），但後句「うれしかった」係收到嘢嘅感動，くれる 最自然；イ 「作ってあげて」係「我幫阿媽整」，方向完全反咗，變咗我服侍阿媽，前後矛盾。

Day 15（N4）：敬語入門（尊敬語・謙讓語・丁寧語）

今日其實已經偷偷接觸咗敬語嘅邊緣——差し上げる・いただく・くださる 全部都係敬語成員！下一課正式拆解日文的敬語系統：點解「行く」對長輩要講「いらっしゃる」，「食べる」要講「召し上がる」；咩係尊敬語、咩係謙讓語，同埋「お／ご〜です」嘅萬用丁寧句式。學咗授受動詞再學敬語，你會發現兩者係兄弟——都係睇「我企邊度」！明天見！
